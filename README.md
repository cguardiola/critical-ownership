# Critical Ownership
This repository includes supplementary evaluation logs and shared conversation during sessions with differente Large Language Models (LLMs) used as examples and ilustrative material in the paper **"Critical Ownership: A Key Competency for Agentic AI Operators"**

The purpose of the repository is to make these interactions available for inspection, allowing readers to access the original sessions and verify the responses generated by the models at the time they were consulted. This provides a transparent record of the interactions on which specific observations in the paper are based.

The repository is organised into two directories:

## performativity

This directory contains prompts and interaction sessions illustrating the **performativity of generative AI**.

The included examples show how, when the same question is posed in different sessions, an LLM may generate different responses. These interactions are intended to illustrate the epistemological problem associated with the performative nature of generative AI: the model does not simply retrieve a fixed piece of information, but generates content anew in response to each interaction.

## illusion of rigor

This directory contains interaction sessions illustrating the **illusion of rigour** and the problem of **systemic hallucination** in LLMs.

The examples show how different models, model versions, or parameter configurations may produce different responses to the same request. They are intended to illustrate how grammatical fluency and apparent coherence can create an impression of rigour that does not necessarily correspond to epistemic reliability.

## Preservation of the evidence

Each folder contains both Prompts.md file with links to the corresponding LLM interaction and a **literal transcript of each session**.

The transcripts are included as a preservation mechanism in case the original interaction links become unavailable or expire. They therefore provide a contemporaneous record of the responses analysed in the paper, independently of the continued availability of the original sessions.

The repository is intended to support the **traceability and transparency** of the examples discussed in the paper and to allow readers to examine the underlying interactions directly.
